# A seed only adds; the hop rule never hides a folder-admitted paper

Adding a seed never removes a paper from the plot, and unticking a hop or
switching direction never hides a library paper a ticked folder admits: the
hop rule gates only papers the folder rule does not admit. Before this rule a
seed replaced the graph and every unconnected paper in the folder vanished
(the reader's complaint is quoted in the scope-rail spec). The rules therefore
run in a fixed order, folder rule then hop rule then filters, and that order
is part of the contract, not an implementation choice.
